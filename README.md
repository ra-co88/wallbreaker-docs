# wallbreaker-docs

Documentation & user-guide site for
[Wallbreaker](https://github.com/JailbrokenAI/wallbreaker) — the agentic LLM
red-team harness. Built with Nextra 4 (Next.js), themed to match the project's
web dashboard, deployed on Vercel.

Development fork of the project:
[pt-act/wallbreaker](https://github.com/pt-act/wallbreaker).

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository into Vercel (auto-detected as Next.js) — see
[DEPLOY.md](./DEPLOY.md).
