# Installation

## Prerequisites

| Tool | Minimum | Notes |
|------|---------|-------|
| Python | 3.11+ | f-string typing required |
| Git | any | Clone & update |
| Node.js | 18+ | Dashboard only |

<Callout type="info">Python and Git are sufficient for the CLI/TUI. Node.js is only for the web dashboard.</Callout>

## Clone & Install

<Terminal lines={[
  { prompt: "$ ", cmd: "git clone https://github.com/JailbrokenAI/wallbreaker.git && cd wallbreaker" },
  { prompt: "$ ", cmd: "python -m venv .venv && source .venv/bin/activate" },
  { prompt: "(.venv) $ ", cmd: 'pip install -e ".[dashboard,barcodes,stego]"' },
]} />

<Callout type="info">Need the test suite too? Add `dev`: `pip install -e ".[dev,dashboard,barcodes,stego]"`. Available extras: `dev`, `dashboard`, `barcodes`, `stego`.</Callout>
]} />

## Keyless Claude Code CLI

If you have the `claude` CLI installed, Wallbreaker can use it as the attacker brain — no API key required:

<Terminal lines={[{ prompt: "$ ", cmd: "which claude", comment: "# verify it is on PATH" }]} />
